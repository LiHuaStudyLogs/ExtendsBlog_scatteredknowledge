## 概念扫盲
* Github 是基于git的提供 托管代码服务[^1]+协作开发 两大功能的平台  
Github是远程仓库的载体/
* Git 是一个版本管理[^2]工具，实现本地仓库的创建、修改、与Github远程仓库同步
* vscode 上边支持Git和Github，实现git相关的命令行可视化

## 主要的命令行操作
1. git init --> 创建本地仓库
2. git add 添加修改后的内容
3. git commit -m"自命名" --> 保存当前的版本，提交到本地仓库
4. git remote add origin 远程仓库的地址 --> 把本地库关联远程的库
5. git push origin main --> 把本地的库上传到远程的库*[需要git配置***代理***](#知识扩充代理)
* git logs --> 查看库的版本行为，即每次的commit提交   
` **这些基本的操作使用vscode可视化，vscode终端，cmd实现，更加方便快捷** `

##### 知识扩充：代理  
> 在许多的境外访问、跨服上传文件的操作中  
> 我们会遇到网络请求限制、网络波动等问题  
> 这时候我们通过 -本地设备- -代理(proxy)服务器- -远程设备- 的线程  
> 实现代理伪装请求、代理优化稳定网络来解决我们的问题  
> * 梯子的翻墙其实就是借助一种代理服务器实现的

[^1]: 主要包括code库*的代码托管、pages*网页托管
[^2]: 历史版本找回和回溯 | 解决协作开发的冲突 | 分支管理
